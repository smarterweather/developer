# Attribution

Smarter Weather sources data and relies on open data and open source projects.
This file mirrors the high-level acknowledgements from the Smarter Weather
marketing site. For the full consumer-app library list, see the in-app
acknowledgements page at https://smarterweather.com/acknowledgements.

## Data and map providers

- **National Oceanic and Atmospheric Administration (NOAA)** -- foundational
  environmental and weather data.
- **National Weather Service (NWS)** -- forecasts, watches, warnings, and
  related products.
- **Open Data on AWS** -- public datasets used in our processing pipeline.
- **OpenStreetMap and OpenStreetMap contributors** -- map and geographic
  context. Data is available under the [Open Database License (ODbL)](https://www.openstreetmap.org/copyright).

When you build on Smarter Weather APIs or SDKs, you remain responsible for
complying with upstream license and attribution requirements for any data you
redistribute or display. See the developer terms at
https://smarterweather.com/developers/terms for product-specific obligations.

## Open source libraries (developer-facing)

This repository will ship its own dependencies (SDKs, examples). Each package
documents its third-party licenses in its own `package.json`, `go.mod`, or
equivalent. Refer to those manifests for the exact list and versions.
